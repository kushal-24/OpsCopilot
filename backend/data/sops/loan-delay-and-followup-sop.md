# GreenLeaf Application Delay and Follow-up SOP

## Stalled applications
An application is considered stalled if it has no activity for 5 calendar days. The case owner must contact the applicant and record the outcome.

## Pending applications
Applications that stay in progress for more than 30 days are reviewed weekly by the operations lead. The lead decides to continue, request new documents, or close the application as withdrawn.

## Phone applicants
Phone is the most common application channel. A phone application must be keyed into the system the same day, and the applicant receives a reference number by SMS within 2 hours.

## Reporting
The operations lead reviews cycle time weekly. If the average time from Submitted to Closed exceeds 10 days for two consecutive weeks, a process review is opened to find the bottleneck stage.
